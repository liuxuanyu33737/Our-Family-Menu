# 咱家菜单 · 开源空白版

一个无需服务器、无需账号、可以完全离线使用的家庭电子菜单。项目只有一个 `index.html` 文件，不包含任何预置菜品、私人照片或个人备份数据。

## 使用方法

直接用 Chrome、Edge 或手机系统浏览器打开 `index.html`。点击“＋ 添加新菜”录入第一道菜。

## 功能

- 添加、编辑、删除和分类菜品
- 上传菜品照片，并在本地自动压缩
- 搜索和筛选分类
- 选择“今晚想吃”的菜并复制清单
- 导出、导入完整菜单备份
- 完全离线，数据只保存在当前浏览器中
- 手机和电脑响应式界面

## 数据说明

每个设备上的菜单彼此独立。更换设备时，使用页面里的“备份与恢复”功能迁移菜品和照片。

浏览器数据被清除后，本机菜单也会被清除，建议定期导出备份。

## 发布

可以直接把 `index.html` 放进代码仓库，也可以部署到任意静态网页托管服务。准备公开仓库时，请根据自己的需要选择并添加开源许可证。

## 自定义

项目无第三方依赖。页面名称、颜色和文字都在 `index.html` 中，可直接修改。
